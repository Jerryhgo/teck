### speech to text:
https://github.com/openai/whisper
1. install whisper
2. install ffmpeg
3. install pytube(pytubefix)  
https://github.com/pytube/pytube
4. extract audio:  
$ pytube https://youtube.com/watch?v=2lAe1cqCOXo
5. speech to text:  
whisper japanese.wav --model medium --language Japanese --task translate
